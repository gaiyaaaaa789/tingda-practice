# 听打间 · 江西法院书记员训练台

这是一个可离线运行的中文看打、听打训练网站，入口文件为 `index.html`。

## 主要功能

- 看打：原文与输入区左右排列，严格核对汉字、标点、空格和换行；练习过程中不显示对错，交卷后统一校勘并计入正确率。
- 智能判卷：采用字符序列对齐，多录字识别为“插入”、漏录字识别为“缺失”，后续内容仍能正常匹配，避免连锁判错。
- 输入框校勘：交卷后直接在录入框中使用底色标出替换字和插入字，并标出缺失位置。
- 标点修正：输入《、“、‘、〈、【 等左标点时，自动移除输入法额外补入的右标点。
- 听打：使用浏览器中文语音合成按句朗读原文，支持上一句、下一句、重播、逐句重复和朗读速度调整；练习过程中同样不提示错字。
- 自动计时：支持 3、5、10、15 分钟倒计时和不限时正计时；计时开始、暂停、继续、自动交卷均可自动处理。
- 成绩结算：练习中不显示准确率，交卷后一次性计算全文总正确率（正确字数 ÷ 对齐总项数），并统计速度、净速、正确字数、退格次数、练习用时，生成速度趋势和错字校勘。
- 自定义素材：可录入标题、模式、分类、难度、标签、正文，并为听打素材导入本地录音。
- 素材管理：支持搜索、模式筛选、收藏、复制默认素材、编辑和删除自定义素材。
- 数据统计：保存练习历史，展示累计时长、平均速度、平均准确率、最佳净速和最近成绩趋势。
- 本地备份：素材、成绩和设置均保存在当前浏览器中，可导出 JSON 备份并重新导入。
- 其他：深色模式、专注模式、字号调整、按键提示音、错字暂停、忽略标点、禁用退格和快捷操作。
- 默认包含 4 篇江西法院看打素材和 4 篇听打素材，均为训练用模拟材料，不涉及真实案件信息。

## 使用方法

1. 直接双击 `index.html`，或者双击 `打开网站.cmd`。
2. 从左侧素材库选择素材和练习模式。
3. 选择计时方式后点击“开始练习”。
4. 在底部输入框使用中文输入法录入；看打时对照原稿，听打时根据语音录入。
5. 交卷后可查看成绩、趋势和逐字校勘。

## 快捷键

- `Ctrl + Enter`：开始或交卷
- `Esc`：暂停或继续
- `F2`：重播当前句
- `F1 / F3`：上一句 / 下一句
- `Ctrl + Shift + F`：进入或退出专注模式

## 语音和录音说明

默认听打素材使用浏览器系统中文语音。不同电脑的语音音色和断句可能不同，建议在“设置”中选择合适的中文语音。正式训练时，可为自定义听打素材导入 MP3、WAV、M4A 等本地录音，获得更稳定的语速和停顿。

## 数据说明

所有数据只保存在当前浏览器的本地存储中，不会上传网络。清除浏览器网站数据会同时删除素材、成绩和录音，建议定期使用“导出备份”。

## 浏览器建议

建议使用最新版 Chrome、Edge 或其他支持中文输入法、Web Speech API、IndexedDB 和 Dialog 元素的现代浏览器。
